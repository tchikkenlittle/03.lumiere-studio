# Lumière Studio — Portfolio Website

Demo de site de portfólio para fotógrafo de produto e e-commerce, focado
em beleza e skincare. Construído com HTML, CSS e JavaScript puro.

## 🎯 Objetivo
Demonstrar um site dark mode, editorial e responsivo para o nicho de
fotografia de cosméticos. Projeto desenvolvido para portfólio de
vendas no Fiverr.

## 🛠️ Tecnologias
- HTML5 semântico
- CSS3 (variáveis, flexbox, grid, animações)
- JavaScript vanilla (Intersection Observer, menu mobile)
- Formspree (backend do formulário de contato)
- Google Fonts (Playfair Display + Inter)
- Imagens via Unsplash

## 📁 Estrutura do Projeto
- `index.html` — arquivo único com todo o site
- `README.md` — este arquivo
