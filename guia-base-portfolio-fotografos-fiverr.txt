1. O NICHO E POR QUE ELE
=============================================================

Nicho escolhido: Sites de portfólio para fotógrafos de produto e e-commerce.

O mercado-alvo são fotógrafos que atendem marcas Shopify, Amazon, Instagram
DTC, cosméticos, moda, eletrônicos e alimentos embalados. O e-commerce global
está em expansão acelerada — mais de 68% das listagens de produto exigem fotos
profissionais, o que cria uma demanda estrutural crescente por fotógrafos que
precisam de presença digital para conquistar contratos maiores.

Por que este nicho é o melhor ponto de entrada:

- O cliente tem mentalidade de negócio. Ele mede ROI. Briefings mais claros,
  menos drama emocional, menos revisões subjetivas.
- A concorrência de gigs específicos no Fiverr é baixa. Há muitos gigs
  genéricos de "fotógrafo portfolio", mas poucos especializados neste nicho.
- A estética do nicho é totalmente executável com HTML/CSS/JS puro. Dark mode,
  grids limpos e hover effects são vibe coding puro.
- Fotógrafos de produto atualizam portfólio frequentemente, gerando demanda
  por atualizações recorrentes — ou seja, clientes que voltam.

O argumento central de venda para o cliente:

"Você fotografa produtos para marcas premium. Seu site precisa fazer o mesmo —
apresentar seu trabalho como uma marca premium apresenta seus produtos. Eu
construo isso com código limpo, rápido e sem os compromissos de qualidade dos
construtores de sites genéricos."

2. PERFIL DO SEU CLIENTE IDEAL
=============================================================

Quem é esse fotógrafo:

- Freelancer ou pequeno estúdio, geralmente 1 a 3 pessoas
- Trabalha com marcas de e-commerce: moda, beleza, eletrônicos, alimentos,
  utensílios domésticos
- Tem perfil no Instagram, mas o portfólio online é fraco ou inexistente
- Busca clientes no Fiverr, LinkedIn ou por indicação
- Fatura entre US$ 2.000 e US$ 15.000 por mês
- Sabe que um site profissional atrairia clientes maiores
- Está acostumado a pagar por ferramentas e serviços (Adobe CC, estúdio,
  equipamento)

O que ele quer do site:

- Que as fotos sejam as estrelas — nada competindo com elas visualmente
- Credibilidade imediata para marcas que pesquisam o fotógrafo online
- Um lugar claro para apresentar seus serviços e preços
- Formulário fácil de contato e pedido de orçamento
- Carregamento rápido (marcas acessam de desktop, muitas vezes em WiFi
  corporativo)

O que ele NÃO quer:

- Templates genéricos que qualquer fotógrafo tem
- Sites lentos cheios de plugins
- Design que compete visualmente com as fotos
- Processo complicado de atualização de conteúdo

4. IDENTIDADE VISUAL — PADRÃO DO NICHO
=============================================================

Esta é a linguagem visual que o mercado de fotografia de produto entende como
"premium". Use como padrão nos seus templates.

PALETA DE CORES (Dark Mode — Default)

  Fundo principal:     #0A0A0A  (preto profundo)
  Fundo secundário:    #111827  (cinza escuro para seções alternadas)
  Texto primário:      #F9FAFB  (branco suave)
  Texto secundário:    #9CA3AF  (cinza médio para subtítulos e body)

  Accent — personalize por cliente:
  → Dourado/Luxo:      #C9A84C
  → Sage/Clean:        #6B8F71
  → Coral/Moderno:     #E07A5F
  → Azul/Tech:         #3B82F6

TIPOGRAFIA

  Títulos (H1, H2):    Playfair Display ou Cormorant Garamond
                       (serif, editorial, sensação premium)
  Subtítulos (H3):     DM Sans SemiBold ou Inter SemiBold
  Corpo de texto:      Inter Regular ou DM Sans Regular

  Importar via Google Fonts:
  Playfair Display (wght 400;700) + Inter (wght 300;400;600)

LAYOUT E ESPAÇAMENTO

  Container máximo:    1280px
  Padding lateral:     clamp(1.5rem, 5vw, 4rem) — responsivo automático
  Espaço entre seções: 120px desktop / 80px mobile
  Gap de galeria:      8px a 16px (grid apertado = sensação editorial)
  Border-radius:       4px a 8px (evitar cards arredondados demais)

EFEITOS E ANIMAÇÕES

  Hover na galeria: a imagem faz scale(1.03) com transição de 0.4s e um
  overlay escuro (rgba 0,0,0,0.6) aparece com opacity de 0 para 1 em 0.3s,
  mostrando o título do projeto.

  Fade-in ao scroll: elementos começam com opacity 0 e translateY(30px),
  e quando entram na viewport via Intersection Observer recebem a classe
  "visible" que transiciona para opacity 1 e translateY(0) em 0.6s.

5. STACK TÉCNICO — O QUE USAR
=============================================================

O que você produz e por que é vantagem:

  HTML5 semântico    → Base de tudo. Sites mais leves e melhor SEO que
                        WordPress.
  CSS3 puro          → Estilo e animações sem dependências externas.
  Vanilla JavaScript → Interatividade sem jQuery nem overhead desnecessário.
  Formspree.io       → Formulários funcionais, gratuito, sem backend.
  Google Fonts       → Tipografia sem custo.

O que NÃO usar e por quê:

  WordPress          → Pesado, lento, vulnerável. Foge do seu diferencial.
  Bootstrap completo → Carrega CSS desnecessário, visual genérico.
  jQuery             → Obsoleto para o que você precisa.
  GSAP/Three.js      → Overkill para pacotes Basic e Standard.
  Wix / Squarespace  → Isso é o que você está substituindo. Nunca entregue.

Hospedagem gratuita para indicar ao cliente:

  1. Netlify — drag & drop da pasta, HTTPS automático. Recomendado.
  2. GitHub Pages — perfeito para quem tem conta GitHub.
  3. Vercel — alternativa sólida, igual ao Netlify em facilidade.

7. PROTÓTIPO: ROTEIRO DO PRIMEIRO MODELO
=============================================================

FASE 1 — PLANEJAMENTO (30 min)

  - Decida a identidade do fotógrafo fictício (nome, especialidade, cidade).
    Exemplo: "Mira Lens Studio — Product Photography for Beauty Brands | NY"
  - Escolha a cor accent (dourado, sage, coral ou azul)
  - Selecione 12 a 16 fotos do Unsplash que representem o estilo
  - Escreva 3 a 5 frases de headline e bio (use IA para ajudar)

FASE 2 — VIBE CODING DO HTML BASE (1 a 2 horas)

  Prompt modelo para usar no seu AI:

  "Crie um site de portfólio de página única para um fotógrafo de produto
  de e-commerce chamado [NOME]. O design deve ser dark mode (fundo #0A0A0A),
  com tipografia Playfair Display para títulos e Inter para corpo. Inclua:
  header fixo com logo e nav, hero full-screen, galeria em grid 3 colunas com
  hover overlay, seção sobre, seção de serviços com 3 cards, e formulário de
  contato. HTML + CSS + JS em arquivo único. Sem frameworks externos.
  Responsivo mobile-first."

FASE 3 — REFINAMENTO VISUAL (1 a 2 horas)

  - Substitua imagens placeholder por fotos reais do Unsplash
  - Ajuste cores do accent para combinar com as fotos escolhidas
  - Revise tipografia: tamanhos, pesos, espaçamento de linha
  - Adicione animações de scroll com Intersection Observer
  - Ajuste espaçamento entre seções (mínimo 80px mobile)
  - Verifique contraste de acessibilidade (texto vs. fundo)

FASE 4 — TESTES DE RESPONSIVIDADE (30 a 45 min)

  Abra o Chrome DevTools (F12) → Toggle Device Toolbar e teste:

  375px  → Mobile pequeno: texto não cortado, galeria em 1 coluna, nav ok
  414px  → Mobile médio: mesmos checks
  768px  → Tablet: galeria em 2 colunas, layout intermediário
  1280px → Desktop: layout completo, sem estiramentos
  1440px → Wide: container máximo respeitado

FASE 5 — DEPLOY DO DEMO (15 min)

  - Crie conta gratuita no Netlify (netlify.com)
  - Faça drag & drop da pasta do site
  - Copie o link público gerado (ex: mira-lens.netlify.app)
  - Use esse link nas imagens de capa do gig no Fiverr

16. ARMADILHAS E COMO EVITAR
=============================================================

Scope creep
→ Defina no gig: "Inclui até X revisões. Mudanças de estrutura fora do
  escopo acordado têm custo adicional."

Imagens do cliente em baixa resolução
→ Adicione na FAQ: "Please provide images at minimum 2000px wide for best
  results."

Cliente sem ideia de hospedagem
→ Inclua um guia de 1 página sobre como subir no Netlify. Isso evita 80%
  das confusões pós-entrega.

Revisões infinitas
→ Especifique o número de rodadas. "Rodada de revisão = uma lista
  consolidada de mudanças, não múltiplas mensagens separadas."

Site lento por imagens não comprimidas
→ Sempre comprima as imagens antes de entregar. Meta: menos de 200kb por
  imagem de galeria.

Layout quebrado no Safari
→ Teste sempre no Safari via BrowserStack (gratuito). Algumas propriedades
  CSS se comportam diferente no Safari.

Pedir review de forma invasiva
→ Uma mensagem educada ao entregar: "Se o resultado superou suas
  expectativas, ficaria grato por uma avaliação!" Nunca implore.

Precificar muito baixo
→ Abaixo de US$ 120 você atrai clientes de baixa qualidade e cria
  ancoragem de preço difícil de reverter.

  }

JS — Intersection Observer para fade-in ao scroll:

  const reveals = document.querySelectorAll('.reveal');
  const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        entry.target.classList.add('visible');

    });
  }, { threshold: 0.15 });
